What the first build could not answer

The first build of this demonstration published 976 components for these three studies, and the studies shared none of them: each minted its own, and a query that joined on a shared component returned nothing. The README said so and kept the queries as a specification. The second build composes the three study models from the same component libraries, so the join is the component, and this page is the specification running.
